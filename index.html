About Me

Professional Profile

Saya adalah seorang Staff Admin dengan pengalaman dalam pengelolaan data, administrasi operasional, digital marketing, dan pengembangan sistem kerja. Saya terbiasa bekerja dengan data dalam jumlah besar serta melakukan input, pembaruan, pengecekan, validasi, dan monitoring data untuk memastikan informasi tetap akurat dan terstruktur.

Memiliki pengalaman dalam mengelola Amazon Product Listing, termasuk pengelolaan informasi produk, harga, stok, dan diskon. Saya juga terbiasa menggunakan Microsoft Excel, Pivot Table, Google Sheets, dan tools pendukung lainnya untuk membantu pengolahan data dan meningkatkan efisiensi pekerjaan operasional.

Dalam pengalaman sebagai Technical Operation HQ, saya menangani pengolahan dan analisis data menggunakan SQL, Microsoft Excel, dashboard, API, dan Regular Expression. Pekerjaan tersebut mencakup pengecekan data, validasi, perbandingan data dari berbagai sumber, serta pembaruan data melalui API.

Saya memiliki kemampuan dalam SQL dan pengolahan database menggunakan MySQL, PostgreSQL, dan SQL Server. Saat ini saya terus mengembangkan kemampuan di bidang database dan SQL Server melalui pembelajaran, latihan query, serta project portfolio yang saya dokumentasikan sebagai bagian dari pengembangan kemampuan teknis.

Selain bidang data dan database, saya memiliki kemampuan dalam web development menggunakan HTML, CSS, Bootstrap, PHP, dan JavaScript. Saya juga mempelajari Python sebagai bagian dari pengembangan kemampuan di bidang teknologi dan pengolahan data.

Saya memiliki karakter kerja yang teliti, sistematis, bertanggung jawab, dan berorientasi pada solusi. Saya terbiasa mempelajari tools dan teknologi baru serta mengembangkan kemampuan melalui pengalaman kerja, pembelajaran, sertifikasi, dan project portfolio.

About Me

Professional Profile

Saya adalah Staff Admin Executive dengan pengalaman dalam pengelolaan data, administrasi operasional, otomasi sistem kerja, dan digital marketing. Terbiasa bekerja dengan data dalam jumlah besar serta melakukan pembaruan, pengecekan, dan validasi data untuk memastikan informasi tetap akurat dan konsisten.

Berpengalaman mengelola listing produk Amazon, termasuk melakukan pembaruan harga, stok, dan diskon secara berkala. Saya juga mengembangkan sistem pendukung pekerjaan menggunakan Microsoft Excel dan Google Sheets, termasuk penggunaan rumus, Pivot Table, VBA Macro, dan Google Apps Script untuk membantu meningkatkan efisiensi pekerjaan operasional tim.

Memiliki pengalaman dalam pengolahan database dan SQL, termasuk menggunakan MySQL untuk mengelola serta menganalisis data. Saya juga berpengalaman menggunakan Postman untuk melakukan integrasi dan pembaruan data melalui API, serta menggunakan Regular Expression untuk membantu proses validasi dan pengolahan data.

Dalam pengalaman sebagai Technical Operation HQ, saya terlibat dalam pengelolaan dan analisis data pajak daerah menggunakan dashboard, SQL, dan Microsoft Excel. Pekerjaan tersebut meliputi membandingkan data dari sumber eksternal dan internal, memperbarui serta menambahkan data wajib pajak melalui API, melakukan validasi data, dan melakukan audit status wajib pajak sebelum ditindaklanjuti oleh tim operasional.

Selain pengalaman administrasi dan pengolahan data, saya terus mengembangkan kemampuan di bidang web development dengan mempelajari HTML, CSS, Bootstrap, Tailwind CSS, PHP, JavaScript, Python, jQuery, dan AJAX. Saya tertarik menggabungkan kemampuan administrasi, pengolahan data, dan teknologi untuk membuat proses kerja yang lebih efektif dan terstruktur.

Saya memiliki karakter kerja yang teliti, sistematis, dan berorientasi pada solusi. Saya juga terbiasa mempelajari tools dan teknologi baru untuk mendukung kebutuhan pekerjaan serta meningkatkan kemampuan profesional saya.
